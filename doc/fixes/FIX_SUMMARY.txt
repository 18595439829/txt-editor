【问题描述】
================================================================================

用户报告:
  "复制粘贴的图片，每次保存完，刷新之后，再预览就加载不出来了"

现象:
  1. 粘贴图片到编辑器 ✓ 成功
  2. 文件自动保存 ✓ 成功
  3. 刷新页面 ✓ 成功
  4. 预览区域 ✗ 图片无法显示

================================================================================
【根本原因】
================================================================================

数据库初始化竞态条件:
  
  时刻 1: 页面刷新
  时刻 2: ImageCacheManager 初始化，this.db = null
  时刻 3: updatePreview() 被调用
  时刻 4: updatePreview() 调用 imageCache.getImage(id)
  时刻 5: ❌ getImage() 检查 this.db，发现为 null
  时刻 6: ❌ getImage() 直接返回 null（不等待初始化）
  时刻 7: 图片无法显示
  时刻 8: 后续某个时刻，fileManager.db 初始化完成（但已晚）

问题代码:
  - js/core/ImageCacheManager.js 第 15-25 行: getDB() 未等待初始化
  - js/core/ImageCacheManager.js 第 89-109 行: getImage() 同步检查 this.db

【技术细节】
================================================================================

为什么原始代码失败:
  
  原始的 getImage() 是同步检查的 Promise:
    ```javascript
    getImage(id) {
      return new Promise((resolve) => {
        if (!this.db) {         // ← 同步检查
          resolve(null);        // ← 立即返回 null
          return;
        }
        // ... 异步查询逻辑
      });
    }
    ```

  问题: 同步检查在异步初始化完成前就返回了

新代码如何解决:

  ```javascript
  getImage(id) {
    return (async () => {
      const db = await this.getDB();  // ← 等待初始化
      if (!db) return null;
      
      return new Promise((resolve) => {
        // ... 异步查询逻辑
      });
    })();
  }
  ```

  优点: 返回异步 Promise，等待初始化完成后再查询
