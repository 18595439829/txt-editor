# BugFix: 修复弹窗点击外部不自动关闭问题

## 问题描述
在 editor.html 中，点击弹窗触发按钮或其他元素时，打开的弹窗（语法帮助、全局缓存、文件缓存等）没有自动关闭，影响用户体验。

## 修复内容

### 1. 增强全局点击事件处理 (line 566-611)
- 添加语法帮助弹窗的外部点击关闭逻辑
- 添加全局缓存弹窗的外部点击关闭逻辑
- 添加文件缓存弹窗的外部点击关闭逻辑
- 增加模态框背景遮罩点击关闭逻辑
- 确保点击对应按钮本身时不会误关闭弹窗

### 2. 优化缓存按钮的点击行为 (line 864-875, 910-921)
- 实现全局缓存按钮 toggle 功能：再次点击可关闭弹窗
- 实现文件缓存按钮 toggle 功能：再次点击可关闭弹窗

## 修改文件
- `editor.html` - 增加 82 行，修改 4 处

## 关键改进
✅ 点击弹窗外部区域自动关闭
✅ 再次点击按钮可切换弹窗开闭状态
✅ 避免点击按钮时因全局事件误关闭
✅ 提升用户交互体验

### 缓存按钮 Toggle 功能
```javascript
cacheBtn.addEventListener("click", async () => {
  if (cachePopup.classList.contains("show")) {
    cachePopup.classList.remove("show");
  } else {
    await updateGlobalCacheUI();
    cachePopup.classList.add("show");
  }
});
```
