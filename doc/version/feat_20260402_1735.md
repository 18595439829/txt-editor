# Feature: 全项目导入导出功能重设计 - 完整项目备份恢复

## 功能概述

重新设计了导入/导出功能，实现了完整的项目级别的备份和恢复能力。新功能允许用户：

1. **导出功能**：选择要导出的文件，支持 ZIP 和 JSON 两种格式，自动包含文件关联的所有图片缓存
2. **导入功能**：完整恢复备份数据，清空现有内容后导入新数据，自动清理孤立缓存

## 核心变更

### 1. 新增 API 方法

#### FileManager.js
```javascript
async deleteAllFiles()  // 删除所有文件
```
- 用于全量清空现有文件
- 返回删除的文件数量

#### DataExporter.js
```javascript
async exportSelectedFilesWithModal(options)
  // 显示文件选择对话框并导出
  // 用户可以选择导出哪些文件
  // 支持 ZIP 和 JSON 两种格式

async exportSelectedFilesAsZip(selectedIds, options)
  // 将选定文件导出为 ZIP 格式
  // 包含 files/ 和 resources/ 结构

async exportSelectedFilesAsJson(selectedIds, options)
  // 将选定文件导出为 JSON 格式
  // 包含完整的文件和资源数据
```

#### DataImporter.js
```javascript
async importFullProjectWithConfirm(file)
  // 全量覆盖导入（带二次确认）
  // 验证文件格式，显示确认对话框
  // 用户确认后执行覆盖导入

async clearAllThenImport(data, sourceFile)
  // 执行全量覆盖导入的核心逻辑
  // 步骤：删除文件 → 删除缓存 → 导入文件 → 导入缓存 → 清理孤立缓存

async parseZipFile(file)
  // 解析 ZIP 文件的辅助方法
  // 支持 3.2 版本的项目备份格式
```

#### FileListImportModal.js
```javascript
setMode(mode)  // 切换模态框模式（'import' 或 'export'）
```

- 导出模式：显示格式选择
- 导入模式：显示冲突检测（保持原有功能）

### 3. 功能工作流

#### 导出工作流
```
用户点击"导出清单"
  ↓
exporter.exportSelectedFilesWithModal()
  ↓
显示文件列表选择对话框（modal 模式：'export'）
  ↓
用户勾选要导出的文件 + 选择格式（ZIP/JSON）
  ↓
点击"导出"按钮
  ↓
exportSelectedFilesAsZip() 或 exportSelectedFilesAsJson()
  ↓
收集选定文件的所有关联资源
  ↓
触发浏览器下载
```

#### 导入工作流
```
用户点击"导入清单"
  ↓
选择 JSON/ZIP 文件
  ↓
importer.importFullProjectWithConfirm(file)
  ↓
验证文件格式
  ↓
显示确认对话框："此操作将删除所有现有文件，确认覆盖吗？"
  ↓
用户点击"确认"
  ↓
clearAllThenImport()
  ├─ 步骤1：删除所有现有文件（fileManager.deleteAllFiles）
  ├─ 步骤2：清空所有图片缓存（imageCache.clearCache）
  ├─ 步骤3：导入新文件
  ├─ 步骤4：导入新图片缓存
  └─ 步骤5：清理孤立缓存（imageCache.cleanupUnusedCache）
  ↓
刷新文件列表，加载第一个文件
  ↓
显示成功提示
```

## 数据格式

### 导出格式 - ZIP (v3.2)
```
project-backup-20260402-173500.zip
├── metadata.json               # 元数据
├── files/
│   ├── 文档1.md
│   ├── 文档2.md
│   └── ...
└── resources/
    ├── images/
    │   ├── [图片ID].img
    │   └── ...
    └── manifest.json           # 资源清单
```

### 导出格式 - JSON (v3.2)
```json
{
  "version": "3.2",
  "type": "project-backup",
  "exportTime": "2026-04-02T17:35:00.000Z",
  "exportType": "selected-files",
  "summary": {
    "selectedCount": 3,
    "imagesCount": 8,
    "totalSize": 512000
  },
  "statistics": { /* 统计信息 */ },
  "files": [ /* 文件数组 */ ],
  "resources": [ /* 资源数组，包含完整 dataUrl */ ]
}
```

## 关键改进

### ✅ 架构改进
- **双模式组件**：FileListImportModal 现在支持导出和导入两种模式
- **清晰的 API**：新增方法专门处理全量覆盖场景
- **完整的错误处理**：ZIP 解析、格式验证、导入失败等都有完善的错误处理

### ✅ 用户体验改进
- **文件选择**：导出时可以选择具体导出哪些文件
- **二次确认**：导入时有确认对话框，防止误操作
- **自动清理**：导入完成后自动清理孤立缓存
- **统计信息**：显示导入文件数和图片数

### ✅ 数据完整性
- **完整备份**：导出包含所有文件内容和关联的图片缓存
- **格式多样化**：支持 ZIP 和 JSON 两种格式
- **向下兼容**：导入器支持多个版本的导出格式

### ✅ 功能移除
- 移除了 merge/skip/rename 导入策略（全量覆盖模式）
- 废弃了 importFileListPreview 的导入流程（改用全量覆盖）
