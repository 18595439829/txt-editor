# Fix: 重构工具栏布局 - 文件缓存按钮位置调整

## 问题描述
原有的工具栏布局中，文件缓存按钮位于项目级工具栏（header-actions）中，与语法帮助、全局缓存等项目级功能混在一起。这不符合功能职责划分，容易造成用户困惑。

## 修复内容

### 1. 工具栏分层架构重构
**项目级工具栏**（header-actions）- 针对整个项目的操作：
- ❓ 语法帮助 - 查看Markdown语法
- 💾 全局缓存 - 管理项目中所有图片缓存
- 📋 导出清单 - 导出所有文件及缓存
- 📥 导入清单 - 导入所有文件及缓存

**文档级工具栏**（editor-wrapper toolbar）- 针对当前编辑文档的操作：
- 🖼️ 插入图片 - 向当前文档插入图片
- 📁 文件缓存 - 管理当前文档的缓存（新增位置）
- ✏️ 重命名 - 重命名当前文档
- 🗑️ 删除 - 删除当前文档

### 2. 修改文件
- `editor.html` - 文件缓存按钮从header-actions移至editor-wrapper toolbar

### 3. 关键改进
✅ 工具栏功能分层清晰
✅ 用户易于理解功能归属
✅ 项目级和文档级操作明确区分
✅ 为后续"导出/导入全部内容及缓存"功能预留了位置

## 代码变更位置
- 删除：header-actions中的文件缓存按钮（原line 37-42）
- 新增：editor-wrapper toolbar中文件缓存按钮（新line 182-189）
- 按钮样式：保持与插入图片按钮一致，添加file-cache-btn类
