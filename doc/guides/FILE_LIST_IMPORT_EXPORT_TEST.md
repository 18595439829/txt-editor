## 功能概述

### 导出功能 📤

**文件清单导出** (`📋 导出清单` 按钮)
- 导出所有文件的元数据、统计信息和内容预览
- 格式：JSON（`file-list-{timestamp}.json`）
- 包含内容：
  - 文件统计（数量、总大小、行数、字数等）
  - 单个文件信息（创建/修改时间、行数、字数、预览）
  - 系统元数据（版本、导出时间）

**ZIP导出**（右键菜单"导出详情"）
- 导出为压缩包，包含文件内容和完整元数据
- 包含 `metadata.json` 和各个 `.md` 文件

### 导入功能 📥

**文件清单导入** (`📥 导入清单` 按钮)
- 支持导入 `.json` 或 `.zip` 格式
- 导入前预览，显示：
  - 待导入文件列表
  - 冲突检测结果
  - 导入策略选择
- 支持三种策略：
  - **merge**: 覆盖现有同名文件
  - **skip**: 跳过已存在的文件
  - **rename**: 重命名导入文件（可选）

## 故障排除

### 问题 1: 导出按钮不响应

**症状**: 点击"📋 导出清单"没有反应

**排查步骤**:
```
1. 打开浏览器开发者工具 (F12)
2. 进入 Console 标签页
3. 检查是否有错误信息
4. 确保至少有 1 个文件存在
5. 检查 exporter 是否初始化：
   console.log(exporter);  // 应该显示对象，不是 null
```

**解决方案**:
- 刷新页面
- 检查浏览器缓存
- 确保 DataExporter.js 已加载

### 问题 2: 导入后文件为空

**症状**: 导入成功但导入的文件没有内容

**排查步骤**:
```
1. 检查源 JSON 文件是否包含 content 字段
2. 验证 JSON 格式是否正确：
   console.log(JSON.parse(fileContent));
3. 检查浏览器 IndexedDB：
   F12 → Application → IndexedDB → md_editor_db → files
```

**解决方案**:
- 重新导出原始文件
- 清除浏览器缓存后重新导入
- 检查 DataImporter 的错误日志

### 问题 3: 冲突提示不显示

**症状**: 导入时没有检测到冲突（但实际上有同名文件）

**排查步骤**:
```javascript
// 在 Console 中运行检查
const files = await fileManager.getAllFiles();
console.log("现有文件:", files.map(f => f.name));

// 检查导入的文件
const importData = JSON.parse(您的JSON内容);
console.log("导入文件:", importData.files.map(f => f.name));
```

**解决方案**:
- 刷新后重新尝试
- 检查冲突检测逻辑是否有 bug
- 查看浏览器开发者工具的 Network 标签

### 问题 4: ZIP 导入失败

**症状**: ZIP 文件上传后显示格式错误

**排查步骤**:
```
1. 验证 ZIP 文件是否可用：
   - 用 WinRAR 或 7-Zip 打开
   - 检查是否包含 metadata.json
2. 检查文件大小（是否被截断）
3. 查看浏览器 Console 的具体错误
```

**解决方案**:
- 重新导出 ZIP
- 尝试用 JSON 格式导入
- 检查 JSZip 库是否正确加载
