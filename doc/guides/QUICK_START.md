## 🎯 主要功能概览

### 标题栏按钮（文件列表操作）
- **📋 导出清单** - 导出所有文件清单为JSON/ZIP
- **📥 导入清单** - 从JSON/ZIP导入文件清单

### 右键菜单（单文件操作）
在文件列表中右键点击任意文件，可：
- **📥 导出为 JSON** - 导出单个文件（含关联资源）
- **📦 导出为 ZIP** - 导出单个文件和资源为压缩包
- **📤 导入文件** - 导入JSON或ZIP格式的单个文件

## 📖 使用教程

### 导出文件清单（全量）

#### 场景：备份所有文件
1. 点击标题栏的"📋 导出清单"按钮
2. 选择导出格式：
   - **JSON** - 纯元数据，文件较小
   - **ZIP** - 包含文件内容和图片资源
3. 自动下载文件 `file-list-{时间戳}.json` 或 `.zip`

#### ZIP包含内容
```
file-list-1711953000000.zip
├── metadata.json          # 清单信息
├── files/                 # 文件夹
│   ├── 文件1.md
│   ├── 文件2.md
│   └── ...
└── resources/             # 资源文件夹
    ├── images/
    │   ├── 图片1.jpg
    │   ├── 图片2.png
    │   └── ...
    └── manifest.json      # 资源清单
```

### 导入文件清单

#### 场景：恢复之前备份的所有文件
1. 点击标题栏的"📥 导入清单"按钮
2. 选择之前导出的JSON或ZIP文件
3. 预览界面显示：
   - 待导入文件列表
   - 冲突文件警告（如有）
   - 可勾选/取消选中文件
4. 选择导入策略：
   - **覆盖现有文件** - 更新现有文件内容
   - **跳过现有文件** - 保持现有文件不变
   - **重命名** - 导入时重新命名（避免覆盖）
5. 点击"导入"完成

### 导出单个文件

#### 场景：分享或备份单个文件
1. 在文件列表中右键点击要导出的文件
2. 选择：
   - **📥 导出为 JSON** - 包含文件内容和关联的所有图片
   - **📦 导出为 ZIP** - 以压缩包形式导出
3. 自动下载 `{文件名}-{时间戳}.json` 或 `.zip`

#### 导出内容
```
{
  "version": "3.1",
  "type": "single-file",
  "file": {
    "name": "我的笔记",
    "content": "Markdown内容...",
    "createTime": "2026-03-20T15:30:00Z",
    "updateTime": "2026-04-01T10:30:00Z"
  },
  "resourceCount": 3,
  "resources": [
    {
      "fileName": "图片1.jpg",
      "type": "image",
      "dataUrl": "data:image/jpeg;base64,..."
    },
    ...
  ]
}
```

### 导入单个文件

#### 场景：导入收到的单个文件
1. 在文件列表中右键任意文件，选择"📤 导入文件"
2. 选择JSON或ZIP文件
3. 文件自动导入，资源也会被同时恢复
4. 显示成功提示：`导入成功！文件：filename, 资源：3个`

#### 冲突处理
如果导入的文件名与现有文件重复：
- 默认策略：**合并**（覆盖文件内容，更新时间戳）
- 导入后文件列表自动刷新

## 💡 常见用法

### 完整备份和恢复
```
备份：点击"📋 导出清单" → 选择ZIP格式 → 保存
恢复：点击"📥 导入清单" → 选择之前的ZIP文件 → 导入
```

### 文件同步
```
导出：右键文件 → "📥 导出为ZIP"
分享给他人
接收者：右键导入 → "📤 导入文件" → 选择ZIP
```

### 增量导入
```
导出5个文件的清单
只选择其中3个导入
其他文件保持原样
```

### 合并文件库
```
同时导出两个编辑器的所有文件
导入时选择"覆盖"策略
合并成一个完整的文件库
```

## ⚙️ 导入策略详解

| 策略 | 行为 | 使用场景 |
|-----|-----|---------|
| **覆盖** | 用新内容替换现有文件 | 更新文件、同步备份 |
| **跳过** | 保持现有文件，只导入新文件 | 增量导入、避免丢失本地修改 |
| **重命名** | 导入时自动重命名（避免覆盖） | 保存两个版本、对比查看 |

## 🐛 故障排除

### 导出后找不到文件
**解决**：检查浏览器的下载文件夹，文件名格式为 `file-list-{数字}.zip`

### 导入时提示"文件格式错误"
**解决**：
- 确保文件是从编辑器导出的
- 确保文件完整未损坏
- 尝试重新导出并导入

### 导入后图片没显示
**解决**：
- 检查导出时是否包含了资源
- 清除浏览器缓存（Ctrl+F5）
- 检查浏览器控制台是否有错误

### 导入时冲突太多
**解决**：
- 选择"跳过现有文件"只导入新文件
- 或选择不同的名称以保存两个版本

## 🚀 开始使用

1. **打开编辑器**：在浏览器中打开 `editor.html`
2. **强制刷新**：按 `Ctrl+F5` 更新到最新版本

   - 创建文件：点击"➕"按钮
   - 添加内容：在编辑器中输入或粘贴图片
   - 导出备份：点击"📋 导出清单"
   - 右键操作：在文件上右键选择"导出为JSON"等
