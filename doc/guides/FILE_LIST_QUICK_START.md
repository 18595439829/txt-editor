## 🎯 3 秒了解功能

**导出**: 将编辑器中的所有文件导出为 JSON 或 ZIP

**导入**: 从备份文件导入文件清单，支持冲突检测和多策略处理

---

## 🚀 快速开始

### 导出文件清单

```
1. 点击 📋 导出清单 按钮
   ↓
2. 浏览器自动下载 file-list-{时间戳}.json
   ↓
3. 完成！ ✅
```

**就这么简单！** JSON 文件包含所有文件的内容和统计信息。

### 导入文件清单

```
1. 点击 📥 导入清单 按钮
   ↓
2. 选择 .json 或 .zip 文件
   ↓
3. 预览对话框显示待导入文件
   ↓
4. 勾选要导入的文件
   ↓
5. 点击确认导入
   ↓
6. 完成！文件已导入 ✅
```

## ⚙️ 冲突处理

### 当导入的文件与现有文件重名时会发生什么？

**选项 1: 覆盖 (✅ 默认)**
```
现有文件内容: "旧内容"
导入文件内容: "新内容"
        ↓
覆盖后: "新内容" ✅
```

**选项 2: 跳过**
```
现有文件内容: "旧内容"
导入文件内容: "新内容"
        ↓
导入被跳过: 保留"旧内容" ✅
```

## 🚨 出现问题？

### 导出失败 → "没有文件可导出"

**原因**: 编辑器中没有文件

**解决**: 创建至少 1 个文件后再导出

### 导入失败 → "文件格式错误"

**原因**: 选择的不是有效的 JSON 或 ZIP 文件

**解决**: 检查文件是否是从编辑器导出的

### 导入后文件为空

**原因**: JSON 文件损坏或不完整

**解决**: 使用之前的备份重新导出和导入

### 冲突提示未显示

**原因**: 没有重名文件，所以没有冲突

**解决**: 这是正常的！继续导入即可

## ❓ FAQ

**Q: 导出的文件可以用其他编辑器打开吗？**

A: 可以！JSON 是标准格式，任何文本编辑器都能打开。

**Q: 导入会删除现有文件吗？**

A: 不会。导入只会创建或更新文件，不会删除未选中的文件。

**Q: 如果我不小心导入了错误的文件怎么办？**

A: 使用 Ctrl+Z 撤销，或重新导入正确的备份文件。

**Q: 能导入 Excel 或 Word 文件吗？**

A: 不能。只支持导入从编辑器导出的 JSON 或 ZIP。

**Q: 大文件列表的性能如何？**

A: 支持 100+ 文件的导入导出，速度很快 (< 5 秒)。
