# 📝 Markdown 文本编辑器 - 多文件版

一个功能完整的网页版 Markdown 文本编辑器，支持多文件管理、实时预览、图片缓存管理和离线使用。

## ✨ 核心特性

### 多文件管理
- ✅ **文件列表**：左侧面板显示所有文件，快速切换编辑
- ✅ **创建文件**：点击➕按钮快速创建新文件
- ✅ **编辑文件**：支持重命名和删除文件
- ✅ **自动保存**：切换文件时自动保存内容
- ✅ **智能排序**：按最后编辑时间排序（最新优先）

### 编辑功能
- ✅ **实时预览**：左侧编辑，右侧实时显示渲染效果
- ✅ **预览区控制**：一键隐藏预览区扩大编辑空间
- ✅ **Markdown 语法支持**：支持所有基础 Markdown 语法
- ✅ **语法帮助**：标题栏快速查看 Markdown 语法提示
- ✅ **响应式设计**：完美适配桌面和移动设备

### 图片管理
- ✅ **三种插入方式**：直接粘贴、本地上传、在线链接
- ✅ **拖拽上传**：支持拖拽图片到上传区域
- ✅ **图片缓存**：自动缓存上传的图片（数百MB 容量）
- ✅ **文件级缓存管理**：查看和清空当前文件的缓存
- ✅ **全局缓存管理**：一键释放所有缓存

## 🚀 快速开始

### 系统要求
- 现代浏览器（Chrome、Firefox、Safari、Edge）
- 无需安装任何依赖，直接在浏览器打开即可使用

### 基本操作

#### 文件管理
1. **创建文件**：点击左侧 ➕ 按钮创建新文件
2. **切换文件**：点击左侧文件列表项切换编辑
3. **重命名文件**：点击工具栏的 ✏️ 按钮
4. **删除文件**：点击工具栏的 🗑️ 按钮（删除时自动清理缓存）

#### 编辑内容
1. **编辑文本**：在左侧编辑区输入 Markdown 文本
2. **实时预览**：右侧预览区会实时显示渲染效果
3. **隐藏预览**：点击分割条上的按钮切换预览显示

#### 插入图片
1. **打开对话框**：点击 🖼️ 插入图片 按钮
2. **选择方式**：在线链接或本地上传两个标签页
3. **输入信息**：填写图片 URL/选择文件和描述
4. **插入图片**：点击确认在光标位置插入图片语法

#### 缓存管理
1. **全局缓存**：点击 💾 全局缓存 按钮查看所有缓存
   - 清理孤立缓存：自动删除未被引用的缓存
   - 一键释放：释放所有缓存空间
2. **文件缓存**：点击 📁 文件缓存 按钮查看当前文件的缓存
   - 清空文件缓存：删除该文件的所有缓存图片

## 🔧 技术栈

- **HTML5**：提供页面结构
- **CSS3**：实现样式和响应式设计
- **JavaScript**：实现交互和 Markdown 解析
- **marked.js**：轻量级 Markdown 解析库（从 CDN 加载）
- **IndexedDB**：持久化存储文件和图片缓存（数百MB 容量）
- **Cache API**：支持离线访问和资源缓存
- **Service Worker**：实现离线支持和后台缓存管理

## 💾 存储架构

### IndexedDB 数据库结构
```
md_editor_db (版本 2)
├── files (文件存储)
│   └── {id, name, content, createTime, updateTime}
└── images (图片缓存)
    └── {id, fileId, fileName, dataUrl, size, createTime, mimeType}
```

### 存储容量
- **IndexedDB**：通常 100MB-1GB（取决于浏览器）
- **Cache API**：独立存储空间（用于离线）
- **localStorage**：不再使用（已升级到 IndexedDB）

## 🎯 常见问题

### Q: 编辑的内容会保存吗？
A: 不会自动保存。关闭页面前请手动复制或保存内容。

### Q: 图片缓存上限是多少？
A: 使用 IndexedDB 存储，通常有 **数百MB** 的容量（取决于浏览器），远高于 localStorage 的 5-10MB 限制。同时使用 Cache API 提供离线访问支持。

### Q: 缓存的图片会一直保留吗？
A: 缓存会一直保留到用户手动删除或清空。建议定期清理不使用的缓存图片。

### Q: 支持离线使用吗？
A: 编辑器支持 Service Worker，允许在没有网络的情况下使用（已缓存的图片和应用资源）。首次加载需要网络连接。
