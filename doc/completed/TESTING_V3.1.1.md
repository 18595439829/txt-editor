## 🧪 功能测试清单

### 一、基础功能验证

#### 1.1 文件管理
- [ ] 创建新文件：点击"➕"按钮，输入文件名
- [ ] 编辑文件：在编辑器中输入内容
- [ ] 自动保存：编辑内容后应自动保存到数据库
- [ ] 文件列表刷新：新建文件应出现在文件列表中
- [ ] 切换文件：点击文件列表中的文件，应加载其内容
- [ ] 重命名文件：点击"✏️ 重命名"，修改文件名
- [ ] 删除文件：点击"🗑️ 删除"，确认删除

#### 1.2 图片处理
- [ ] 粘贴图片：直接粘贴图片到编辑器
- [ ] 插入图片链接：点击"🖼️ 插入图片"，输入在线图片URL
- [ ] 本地上传：点击"📁 本地上传"，选择图片文件
- [ ] 拖拽上传：拖拽图片到上传区域
- [ ] 预览显示：预览区域应正确显示所有图片

#### 1.3 缓存管理
- [ ] 全局缓存：点击"💾 全局缓存"，显示所有缓存的图片
- [ ] 文件缓存：点击"📁 文件缓存"，显示当前文件的图片
- [ ] 清空缓存：点击"清空"按钮，应移除所有缓存图片
- [ ] 缓存计数：缓存数量应正确显示

---

### 二、文件列表导出/导入（标题栏按钮）

#### 2.1 导出文件清单为JSON
- [ ] 点击"📋 导出清单"按钮
- [ ] 应下载 `file-list-{timestamp}.json` 文件
- [ ] 验证JSON内容：
  - 包含 `version: "3.1"`
  - 包含 `exportType: "filelist"`
  - 包含文件统计信息（文件数、总大小、行数等）
  - 每个文件包含：id、name、createTime、updateTime、lineCount、wordCount等

#### 2.2 导出文件清单为ZIP
- [ ] 点击"📋 导出清单"后选择ZIP格式选项
- [ ] 应下载 `file-list-{timestamp}.zip` 文件
- [ ] 验证ZIP结构：
  - `metadata.json` - 清单元数据
  - `files/` - 文件夹（包含所有.md文件）
  - `resources/` - 资源文件夹（包含图片）
  - `resources/images/` - 图片文件
  - `resources/manifest.json` - 资源清单

#### 2.3 导入文件清单（JSON）
- [ ] 点击"📥 导入清单"
- [ ] 选择之前导出的JSON文件
- [ ] 应显示导入预览对话框：
  - 显示待导入文件列表
  - 显示冲突警告（如有）
  - 可选择导入策略：覆盖/跳过/重命名
  - 显示已选择文件数
- [ ] 点击"导入"，应成功导入文件

#### 2.4 导入文件清单（ZIP）
- [ ] 点击"📥 导入清单"
- [ ] 选择之前导出的ZIP文件
- [ ] 应正确解析ZIP并显示导入预览
- [ ] 导入后应恢复所有文件和资源

#### 2.5 冲突处理
- [ ] 导入与现有文件同名的清单
- [ ] 应弹出冲突提示
- [ ] 选择"覆盖现有文件"：文件内容应被更新
- [ ] 选择"跳过现有文件"：现有文件不变，跳过导入
- [ ] 选择"重命名"：文件应以新名称导入

### 三、单文件导出（右键菜单）

#### 3.1 右键菜单显示
- [ ] 在文件列表中右键点击任意文件
- [ ] 应弹出右键菜单，包含：
  - "📥 导出为 JSON"
  - "📦 导出为 ZIP"
  - "📤 导入文件"

#### 3.2 导出单文件为JSON
- [ ] 右键点击文件，选择"📥 导出为 JSON"
- [ ] 应下载 `{filename}-{timestamp}.json` 文件
- [ ] 验证内容：
  - `version: "3.1"`
  - `type: "single-file"`
  - `file` 对象包含：id、name、content、createTime、updateTime
  - `resources` 数组包含关联的所有资源

#### 3.3 导出单文件为ZIP
- [ ] 右键点击文件，选择"📦 导出为 ZIP"
- [ ] 应下载 `{filename}-{timestamp}.zip` 文件
- [ ] 验证ZIP结构：
  - `file.md` - 文件内容
  - `metadata.json` - 文件元数据
  - `resources/images/` - 关联的图片
  - `resources/manifest.json` - 资源清单

#### 3.4 导出包含资源的文件
- [ ] 在文件中插入多张图片
- [ ] 导出该文件为JSON/ZIP
- [ ] 验证导出的资源数正确
- [ ] 重新导入，图片应正确显示

### 六、边界情况和错误处理

#### 6.1 空文件列表
- [ ] 在没有文件时，尝试导出文件清单
- [ ] 应显示错误提示"没有文件可导出"
- [ ] 不应生成下载

#### 6.2 无效文件格式
- [ ] 尝试导入非JSON/ZIP文件
- [ ] 应显示错误："不支持的文件格式"

#### 6.3 损坏的ZIP文件
- [ ] 尝试导入一个损坏的ZIP文件
- [ ] 应显示错误，应用不应崩溃

#### 6.4 缺少必要字段
- [ ] 手动编辑JSON文件，删除version字段
- [ ] 导入时应显示验证错误

#### 6.5 大文件处理
- [ ] 创建内容量大的文件（1000+行）
- [ ] 导出/导入应成功，不应卡顿
- [ ] 应显示进度提示（如有）

#### 6.6 多资源导出
- [ ] 在文件中插入10+张图片
- [ ] 导出为ZIP
- [ ] 验证所有资源都被包含
- [ ] 导入后所有图片应正常显示
